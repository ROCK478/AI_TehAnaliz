# ТехАнализ — платформа обучения техническому анализу

Образовательный веб-сервис на **Flask + Jinja + SQLAlchemy**. Пользователь
регистрируется, выбирает одну из 5 акций Мосбиржи и период прогноза, после чего
система:

1. подтягивает котировки по API Московской биржи (ISS), строит график;
2. размечает график по правилам теханализа (тренды, уровни, фигуры) с пояснениями;
3. считает индикаторы (RSI, MACD, SMA, Bollinger) и объясняет их «на пальцах»;
4. строит прогноз с ожидаемым изменением (%) и вероятностью;
5. сохраняет прогноз в историю со статусом: **ожидает / сбылся / не сбылся**.

Дополнительно: вкладка **Тарифы** с лимитом прогнозов (1/день на бесплатном),
**Новости**, **Учебник**, **Дневник инвестора**, случайные напоминания про
риск-менеджмент, политика конфиденциальности при регистрации и дисклеймер
«не является ИИР» на всех прогнозах.

## Архитектура

| Файл | Назначение |
|------|-----------|
| `app.py` | точка входа, маршруты, оценка исполнения прогнозов |
| `config.py` | акции, периоды, тарифы, тексты дисклеймера и риск-советов |
| `models.py` | модели SQLAlchemy: `User`, `Forecast`, `DiaryEntry` |
| `extensions.py` | инициализация `db` и `login_manager` |
| `moex.py` | клиент ISS API Мосбиржи (+ оффлайн-фолбэк синтетикой) |
| `analysis.py` | индикаторы и распознавание фигур на чистом Python + пояснения |
| `predictor.py` | **слой прогноза**: rule-based заглушка + готовый слот под нейросеть |
| `train_model.py` | обучение настоящей ML-модели на истории Мосбиржи |
| `templates/`, `static/` | Jinja-шаблоны и CSS |

### Про «нейронку»

Прогноз вынесен в `predictor.py` за единый интерфейс:

```python
predict(features, horizon_days, period) -> {direction, change_pct, probability, model}
```

- **Модель уже обучена** на реальной истории Мосбиржи (`model.pkl`, ~5 лет
  котировок по 5 акциям) → прогноз идёт через ML (`model = "ml"`).
- Под каждый период обучается **своя** модель (RandomForest: классификатор
  направления + регрессор величины), потому что горизонты разные:

  | Период | Горизонт | Accuracy направления |
  |--------|----------|----------------------|
  | Краткосрочный | ~1 неделя | ~0.54 (по сути монетка — неделя близка к случайному блужданию) |
  | Среднесрочный | 2–5 месяцев | ~0.62 |
  | Долгосрочный | 1–2 года | ~0.65 |

  Числа честные: предсказывать рынок по индикаторам сложно, особенно на коротком
  горизонте. Именно поэтому везде стоит дисклеймер «не ИИР».
- Если `model.pkl` удалить — приложение **автоматически** откатится на прозрачную
  rule-based заглушку (`model = "rule-based"`), логика которой объяснена в коде.
- Контракт признаков — `FEATURE_ORDER` в `predictor.py`, общий для обучения и
  инференса. Чтобы вставить собственную нейросеть, сохраните bundle
  `{"features": [...], "models": {period: {clf, reg, scaler}}}` в `model.pkl`
  либо замените `_ml_predict()`.

## Запуск

```bash
cd /Users/viktor/Downloads/AI_TehAnaliz

# 1. создать окружение и поставить зависимости (минимум для запуска)
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt          # numpy/sklearn нужны только для обучения

# 2. запустить
python app.py
```

Откройте **http://127.0.0.1:5001**. База данных SQLite (`tehanaliz.db`) и таблицы
создаются автоматически при первом старте.

> Если нет интернета или Мосбиржа недоступна — `moex.py` отдаёт детерминированный
> синтетический ряд, поэтому приложение полностью работоспособно и оффлайн.

### Переобучить модель

`model.pkl` уже лежит в проекте. Чтобы переобучить на свежих данных:

```bash
source venv/bin/activate
pip install numpy scikit-learn joblib    # уже в requirements.txt
python train_model.py                    # пересоздаст model.pkl (3 модели)
python app.py
```

Скрипт тянет историю Мосбиржи постранично (ISS отдаёт ~500 свечей за запрос,
`moex.py` листает до нескольких тысяч). Чтобы временно вернуться к rule-based
заглушке — удалите/переименуйте `model.pkl`.

## Как тестировать

**Ручной сценарий:**
1. Зарегистрируйтесь (отметьте согласие с политикой конфиденциальности).
2. На странице «Прогноз» выберите акцию и период → «Построить прогноз».
3. Посмотрите график, разметку фигур, индикаторы и обоснование.
4. Попробуйте создать **второй** прогноз — на бесплатном тарифе сработает лимит
   «1 в день» и вас перенаправит на «Тарифы».
5. Смените тариф (демо, без оплаты) и постройте ещё прогнозы.
6. На «Истории» нажмите «Проверить исполнение» — прогнозы с наступившим сроком
   получат статус «сбылся / не сбылся» (для немедленной проверки можно вручную
   изменить `target_date` в БД на прошедшую дату).
7. Проверьте «Новости», «Учебник», «Дневник инвестора».

**Автоматический smoke-тест** (поднимает приложение через тестовый клиент Flask,
проходит весь путь регистрация → прогноз → лимит → оценка → дневник → тарифы):

```bash
source venv/bin/activate
python test_app.py
```

Ожидаемый вывод — `SMOKE TEST PASSED`.

Сервис носит образовательный характер. Все прогнозы — **не являются
индивидуальной инвестиционной рекомендацией (НИИР)**.
